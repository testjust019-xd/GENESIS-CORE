# GENESIS Artifact Engine

The Artifact Engine is a local-first workspace for creating, previewing and keeping small web experiences inside GENESIS Studio.

## Studio workflow

1. Open GENESIS Studio and select **Artifacts** in the navigation.
2. Enter a name and optional description.
3. Edit the starter HTML, including inline CSS and JavaScript.
4. The preview refreshes automatically after a short pause while typing. Use **Refresh now** or Ctrl/⌘ + Enter to refresh immediately.
5. Save the artifact. Select it from the library later to continue editing.
6. Use **New artifact** to start from the starter template, or **Delete** to remove the selected saved artifact.

Ctrl/⌘ + S saves the current artifact. Unsaved edits are flagged; opening another artifact or starting a new one asks before discarding them.

## What it provides

- A browser editor for self-contained HTML, CSS and JavaScript.
- Debounced live preview and manual refresh.
- A sandboxed iframe without same-origin privileges.
- Persistent artifact records in the existing GENESIS SQLite database.
- Create, list, open, update and delete operations through the Studio API.
- A 200 KB UTF-8 HTML payload limit per artifact.
- Responsive layout, subtle interface motion and reduced-motion support.

## API

- `GET /api/artifacts` — list artifact metadata.
- `POST /api/artifacts` — create an artifact (`title`, `description`, `html`).
- `GET /api/artifacts/{id}` — retrieve the artifact and its source.
- `PUT /api/artifacts/{id}` — update its title, description and source.
- `DELETE /api/artifacts/{id}` — delete it.

## Isolation and limitations

The preview runs in an iframe with `sandbox="allow-scripts"` and without `allow-same-origin`. A restrictive Content Security Policy blocks network connections, external assets, forms, plugins, object embeds and base-URL changes. Inline CSS and JavaScript remain enabled so local prototypes can be interactive.

This is a containment layer, not a guarantee that arbitrary untrusted HTML is safe. Only preview code you understand. The preview cannot fetch remote libraries or use external assets; keep prototypes self-contained.

Artifacts are local project data, not public websites. They are not automatically published, hosted externally, or generated by an AI model. Agent-assisted artifact generation, version history, templates and export remain future work.
