# GENESIS Artifact Engine

The Artifact Engine is a local-first workspace for creating, previewing and keeping small web experiences inside GENESIS Studio.

## What it provides

- A browser editor for self-contained HTML, CSS and JavaScript.
- A live preview in a sandboxed iframe (sandbox=allow-scripts, without same-origin access).
- Persistent artifact records in the existing GENESIS SQLite database.
- Create, list, open, update and delete operations through the Studio API.
- A 200 KB UTF-8 HTML payload limit per artifact.

## API

- GET /api/artifacts — list artifact metadata.
- POST /api/artifacts — create an artifact (title, description, html).
- GET /api/artifacts/{id} — retrieve the artifact and its source.
- PUT /api/artifacts/{id} — update its title, description and source.
- DELETE /api/artifacts/{id} — delete it.

## Isolation and limitations

The preview runs in a sandboxed iframe without same-origin privileges. A restrictive Content Security Policy blocks network connections, external assets, forms, plugins and base-URL changes. Inline CSS and JavaScript remain enabled so local prototypes can be interactive. This is a containment layer, not a guarantee that arbitrary untrusted HTML is safe; only preview code you understand.

Artifacts are local project data, not public websites. They are not automatically published, hosted externally, or generated by an AI model. An agent-to-artifact generation workflow can be layered on later with explicit user review.
